SPOTLIGHT 9 — Independent HTML edition

Open index.html to view the website locally.

To publish on GitHub Pages: upload all HTML files, style.css and site.js to the root of a repository, then enable Settings > Pages > Deploy from a branch > main > /(root).

The interactive vocabulary, listening, writing and final-test activities are embedded from existing GitHub Pages sites; the phonetics and grammar quizzes link to Wordwall. These require internet and may be blocked in embedded frames on some browsers. Each embedded activity has an external fallback button.

The design is a new HTML adaptation based on publicly visible Tilda content, not an exact pixel-for-pixel export.
